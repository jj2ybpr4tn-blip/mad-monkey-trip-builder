To build it again, from the trip builder repo on the Mac (pull first):
  npm run -s publish-preview -- --dry-run        (builds the builder into .site/, publishes nothing)
  ALLIN_LAUNCH=1 python3 drafts/all-in-store/src/build.py drafts/all-in-concept/ALL-IN-concept-v4.html \
      .site/mad-monkey-trip-builder/shop/trip-builder drafts/launch-pack/all-in-trips/index.html
Then copy any new films into all-in-trips/v/, update the checksums above, and check it with tools/launch21.py and
tools/wa24test.py (tools/build24.sh builds every copy the checks open).
